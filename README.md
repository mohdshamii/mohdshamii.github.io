## Local Development & Build

### Installation
```bash
git clone https://github.com/codexshami/codexshami.github.io.git
cd codexshami.github.io
npm install
```

### Run Locally (Dev Server)
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Deployment to GitHub Pages

An automated GitHub Actions workflow is provided at `.github/workflows/deploy.yml`:
1. In your GitHub repository, navigate to **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
3. Push to `main`:
   ```bash
   git add .
   git commit -m "feat: synchronize portfolio with updated verified resume"
   git push origin main
   ```
